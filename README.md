##Критичные ошибки
 - не заданы обязательные аргументы командной строки: -a, -p, -r
 - ошибка типа при вводе аргументов командной строки (-p написано не в виде числа и тд.)
 - ошибка переполнения при вводе аргументов командной строки (-p не может быть больше, чем максимальное значения типа int32)

##Не критичные ошибки
 - ошибка при вводе названия команды
 - ошибка в вводе типа вектора
 - ошибка в вводе значений вектора
 - неверное число значений вектора (должно быть 4)
